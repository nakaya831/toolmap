# 外観設計案（SPEC 第10章 Phase 2）

状態：**適用済み・レビュー待ち**。発注者が就寝中のため、設計案を本書に記録したうえで先行適用した。差し戻しがあれば `src/styles/global.css` のトークン（`@layer tokens`）を変えるだけで全体に反映される。

## 1. 性格

「図鑑・フィールドガイド」。読み物ではなく参照資料。判断の基準は次の3つ。

1. 情報密度を優先する。余白で見せない。
2. 表を主役にする。カードに切り分けない。
3. 詳細ページで最も目立つのは「できないこと」と「制約」の2ブロック。

## 2. 配色トークン（5色＋分類12色）

| トークン | ライト | ダーク | 役割 |
| --- | --- | --- | --- |
| `--ink` | `#17191c` | `#e8eaed` | 文字。**「できないこと」ブロックの地**（反転表示） |
| `--ink-2` | `#4b5058` | `#a3a9b2` | 補助文字（一行定義、メタ情報） |
| `--paper` | `#f6f7f9` | `#16181b` | 地。寒色寄りの無彩色。クリームにしない |
| `--paper-2` | `#ffffff` | `#1e2125` | 表の面 |
| `--rule` | `#c9cdd3` | `#3a3f47` | 罫線。太罫（2px）は `--ink` を使う |
| `--link` | `#1a4fb4` | `#8ab4f8` | リンク。**唯一の有彩色** |

装飾のための色は持たない。「できないこと」の強調は色ではなく**反転（ink 地に paper 文字）**で行う。制約表の強調は上下 2px の太罫で行う。

分類12色は OKLCH で明度 0.60・彩度 0.15 に固定し、色相のみ 30° 刻みで割り当てる（ダークでは明度 0.72・彩度 0.13）。色はカテゴリ名の横の小さな正方形にだけ使い、常に文字を併記する。色だけで判別させない。

| 分類 | 色相 |
| --- | --- |
| language 25 / frontend 55 / backend 95 / datastore 145 / data-processing 175 / infrastructure 210 / automation 245 / devops 275 / observability 305 / security 335 / ai 5 / nocode 120 | |

## 3. 書体（2種）

| 役割 | 指定 | 理由 |
| --- | --- | --- |
| 本文・見出し | システム日本語サンセリフ（Hiragino Sans / Yu Gothic UI / Noto Sans JP …） | Webフォントを読み込まない。日本語フォントは数MBになり、図鑑の即応性を損なう |
| 数値・ID・制約の値 | システム等幅（ui-monospace / Consolas …） | 「6分 / 実行」「max_connections = 100」を本文と区別し、表で桁を揃える |

セリフ体は使わない。見出しのトラッキングは広げない。大文字ラベルは使わない。

文字サイズは4段のみ（13 / 15 / 18 / 24px）。行間 1.75。本文の行長は `44em`（日本語 40〜45 字）で上限を切る。表はこの制限を受けない。

## 4. レイアウト概念

- ページ幅 1120px。本文列は 44em で止まるが、表は 1120px まで広がる。表がはみ出す場合は表だけ横スクロール（ページはスクロールさせない）。
- 見出しは下罫線 1px。セクションの区切りは余白ではなく罫線で示す。
- 一覧は「行」で表現する（`.tool-row`、`.cap-list`）。角丸カードは使わない。
- トップの3つの入口は縦罫で区切った3列。モバイルでは横罫の縦積みになる。
- 詳細ページの順序は SPEC 6.2 の通り。「できないこと」は反転ブロック、その直後に制約表。
- リンク文末の矢印記号は使わない。リンクは下線で示す。

## 5. アクセシビリティの床

- `<html lang="ja">`、スキップリンク、`aria-labelledby` 付きセクション、表の `scope`。
- フォーカスリング 3px（`--focus`、オレンジ系。装飾ではなく状態表示なので有彩色を許容）。
- コントラスト：本文 `#17191c` on `#f6f7f9` ≒ 15:1、補助 `#4b5058` on `#f6f7f9` ≒ 7:1。
- `prefers-reduced-motion` でアニメーションを無効化（もともとアニメーションはほぼない）。
- `prefers-color-scheme: dark` に追従。カテゴリ色も明度を上げて再定義。

## 6. 避けた既定表現（SPEC 第10章の禁止事項への対応）

| 禁止 | 対応 |
| --- | --- |
| クリーム地＋セリフ＋テラコッタ | 無彩色地＋サンセリフ。有彩色はリンク青のみ |
| 全要素を同一の角丸カードに | 角丸ゼロ。罫線と表で構成 |
| トラッキング広めの大文字ラベル | 使用しない。ラベルは日本語の通常テキスト |
| リンク文末の矢印 | 使用しない |

## 7. レビュー時に見てほしい点

1. 「できないこと」の反転ブロックが強すぎないか（弱めるなら太罫＋余白に変える案がある）。
2. 分類12色が判別できるか。難しければ色相を隣接分類で離す再配置を行う。
3. 行長 44em が広すぎ／狭すぎないか。
