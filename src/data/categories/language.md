**言語とは何か。** 人間が書いた指示を、コンピュータが実行できる形にするための決まりごとが「プログラミング言語」である。同じ処理を Python でも Go でも TypeScript でも書けるが、得意な分野と「どこで動かせるか」が違う。

**実行環境とは何か。** 書いたコードを実際に動かすプログラムを実行環境（ランタイム）と呼ぶ。たとえば JavaScript はもともとブラウザの中でしか動かなかったが、Node.js という実行環境が生まれてサーバー側でも動くようになった。逆に、ブラウザは JavaScript しか動かせない。だから「画面を作る」なら JavaScript（とその拡張である TypeScript）が必須になる。

**型の違い。** TypeScript・Go・Rust のような静的型付け言語は、書いた時点で「数値のはずの場所に文字列が入っている」といった間違いを見つけてくれる。Python のような動的型付け言語は書くのが早いが、実行するまで間違いに気づけない。学習初期は Python の速さが利点になり、規模が大きくなると型の助けが利点になる。

**隣の分野との境界。** React や FastAPI は「言語」ではなく、言語の上で使う道具（ライブラリ・フレームワーク）である。言語を1つ覚えると、その言語の道具がすべて視野に入る。だから最初の言語選びは、その後に触れる分野を決める。

**最初の一歩。** 1つの言語で「ファイルを読み、集計して、結果を出力する」小さなプログラムを書く。それができれば、画面・サーバー・データ保存のどの分野にも進める。
